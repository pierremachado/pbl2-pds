\begin{frame}{Resolução Adotada}
\begin{block}{Critério de projeto}
Adotamos o fundo de escala como referência para o erro percentual.
Com 8 bits, temos 256 níveis e, para $V_{ref}=2{,}56$ V:
\[
\Delta=\frac{2{,}56}{256}=10\ \text{mV},\qquad
\frac{\Delta}{V_{ref}}\,100\%=0{,}390625\%.
\]
\end{block}
\begin{itemize}
\item Um degrau corresponde a aproximadamente $0{,}39\%$ da escala.
\item No modelo ideal com arredondamento, o erro máximo é meio LSB: $0{,}1953\%$.
\item Lemos os 8 bits mais significativos do ADC de 10 bits. Isso não reduz o número de etapas da conversão interna.
\end{itemize}

\end{frame}
